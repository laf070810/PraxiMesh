# 有状态 Python 类/API 契约

`python-object-api-v1` 接收一个 Python 类，验证构造、方法调用、返回值、内置异常类型和连续操作后的状态。初始题目 `bounded-queue-api` 要求实现有界 FIFO 队列，含 2 个公开、6 个受保护场景及 8 个针对性错解。类接口、多个实例独立性和失败后的状态都是题目要求；不把功能通过视为复杂度或性能证明。

## 内容声明

`interface` 只包含类名、构造参数数量和方法表。例如下面是一个简短的计数器接口，完整题目仍需通用元数据、参考实现及公开/受保护测试。

```json
{
  "class_name": "Counter",
  "constructor_arity": 1,
  "methods": {
    "add": {"arity": 1, "raises": []},
    "read": {"arity": 0, "raises": ["IndexError"]}
  }
}
```

每个测试场景有 `name`、`public`、`operations`、`expected` 四个字段。操作和预期按位置一一对应：

```json
{
  "name": "公开连续调用",
  "public": true,
  "operations": [
    {"new": "a", "args": [2]},
    {"call": "a", "method": "add", "args": [3]},
    {"call": "a", "method": "read", "args": []}
  ],
  "expected": [{"value": null}, {"value": 5}, {"value": 5}]
}
```

构造使用未占用的场景内 ID，合法构造的预期固定为 `{"value": null}`。调用只能引用已经创建的实例及声明的方法。参数数量必须与声明一致。构造参数应在题目声明的有效范围内；构造失败、缺失类或方法、类名对应非类对象，都判为运行错误。

方法返回 JSON 数据，或抛出其 `raises` 中列出的内置异常。允许的异常是 `IndexError`、`KeyError`、`ValueError`、`TypeError`、`OverflowError`、`ZeroDivisionError`。预期异常写作 `{"raises": "IndexError"}`，实际异常必须是该内置类型本身；子类不替代它。异常文本不评分也不回传。声明异常发生后继续后续操作，可验证失败是否意外改变状态；未声明异常结束该场景并报告运行错误。

## 数据与资源边界

正式题目同时包含公开和受保护场景，最多 20 个；每场景 2–64 个操作，至少一次方法调用，最多 8 个实例。接口最多 16 个方法，每次构造/调用最多 8 个参数。类名和方法名采用验证器规定的 ASCII 标识符；不支持可执行 checker、插件字段或其他评测契约的混合字段。

每个场景的操作和预期各自不超过 24,000 UTF-8 JSON 字节、16 层和 4,096 个值节点；数值有限且绝对值不超过 `1e100`。仅支持字符串键的字典、列表、字符串、数值、布尔值和 null。返回 tuple、集合或自定义对象为运行错误。每次成功返回立即保存 JSON 快照，后续原地修改不会改变先前返回值。

比较固定为 `{"kind":"exact","absolute":0,"relative":0}`：结构、键、值及数值类型必须一致，整数、浮点数和布尔值互不替代。所有场景都成功才得到正式通过。公开反馈只包含公开场景名称和判定类别，不包含受保护输入、预期、实际输出或异常细节。

每场景一个新的 WASI 进程，同场景中的实例状态持续有效。沿用 128 MiB guest 内存、15 秒墙钟、fuel 和 32 KiB 输出限制；详见 [WASI 指南](wasi.md)。资源账本每场景预约一个单位，表示保守调用上限，不是实测 CPU 时间或费用；已开始任务不会因提前失败减少已消费的预约单位。取消与租约检查在每个场景执行前进行。

固定驱动在 WASI 内编译源码并创建对象；主机只验证声明和比较返回记录，不导入学员模块。预期值留在控制器，guest 记录始终不可信。gVisor 当前明确拒绝该契约。平台故障不变成 Wrong Answer，也不生成正式学习证据。

## 页面、本地工具与记录

题页提供调用序列、类编辑器提示和异常规则；英文界面翻译操作提示，尚无译文的题意明确回退。Run 与本地 CLI 只执行公开场景，不计正式完成。Submit 使用固定版本、完整场景和真实 worker，沿用私有历史、进度、导出/删除与自愿分享。下载与提交命令见[本地练习指南](local-practice.md)。

多文件包、第三方依赖、原生扩展、异步协议和任意 Python 对象接口不在此契约中。新增这些形式需另外设计并验证隔离、依赖和版本边界。
