# G20 GPU 分享、分组计时榜与表单布局

日期：2026-10-31。实现前基线：`main` 的 `f69f855`。遵循维护者“不占 GPU”的要求，本批没有编译或执行 CUDA、启用设备或生成 GPU 凭证；GPU 记录仅在自有临时数据库中合成，用于验证成绩消费者。

## 交付范围

- 完整正确的 GPU Submit 通过现有正式证据验证及不可变版本摘要核对后，可以单独预览、确认分享和撤回。每次公开读取重新验证，损坏或公开范围不匹配的记录从详情、主页和榜单移除。
- `SharedResult.metric_kind` 区分原顺序测试进度与 GPU 批次计时；新增迁移保留旧记录和旧写入的数据库默认值。旧分享不会随升级扩大公开范围。
- 按题目版本及完整执行环境指纹分榜；每人只取仍公开的最好结果。GPU 中位数四舍五入至 0.001 ms 后排序，同显示分数同名次；不公开原始样本、编译时间、设备详情、源码和测试。
- 正式结果页接入确认入口；管理页正确区分已公开、未公开及已失效的分享。中英规则说明统计范围、计时组成和精度限制。
- 修正 Django `as_p` 表单的复选框与说明分行，以及英文长按钮撑宽手机页面的问题，保留标签关联、键盘确认及表单校验。

用户规则见[分享指南](sharing.md)，设计决定见 [ADR-036](adr/036-gpu-opt-in-leaderboards.md)，运行条件仍统一见 [GPU 部署指南](deployment/gpu.md)。

## 验证边界与剩余工作

上述迁移检查覆盖真实数据库、旧 ORM 写入和角色权限，不代表完整冻结制品回退或 GPU 部署成功。Compose 镜像重建与本地 AI 重放另行记录，不能用上表源码浏览器代替镜像内自检。

GPU 性能数值、完整执行/启动/故障恢复、候选内容参考解与错解仍待独占硬件重放。容器化 GPU 部署、本地 GPU 执行、正式内容发布及外部 CI/运营事项继续按[需求追踪](requirements.md)推进；默认设备列表和题库保持未开放条件。合成计时榜只能证明展示、权限与比较规则，不能作为 CUDA 或真实性能通过的证据。
