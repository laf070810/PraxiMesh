# ADR-014：持久数据的一键 Compose 本地体验

状态：接受，2026-10-30。依据：[RFC-015](../rfcs/015-compose-preview.md)。

采用 `docker compose up --build -d` 启动本地页面体验。固定基础镜像使用默认值，随机实例密钥首次生成后保存在命名卷；现有显式密钥配置继续支持。`core.preview` 在加载 Django 设置前准备配置，并在启动成功后 exec Gunicorn。

新库在卷内私有临时目录完成迁移和完整示例导入，再以拒绝覆盖的硬链接发布。既有数据库只迁移。卷内初始化锁串行化启动，初始化失败不开放 Web。选择此方式是为了让首次失败可重试，同时保护重建后的账号、登录会话、自定义内容和撤回状态。

不使用每次启动重导内容、固定共享密钥或默认丢弃数据卷的方式。此入口只处理回环、SQLite、判题与 AI 关闭的本地配置；生产的 PostgreSQL 角色、备份、排空、执行探针及代际恢复仍由部署协调器负责。

55 项定向检查与真实 Compose 初始化/容器重建检查通过，证据与边界见 RFC。CI 已增加同一入口的重放定义；服务端 CI 运行仍未验证。修改运行时或正式评测策略时，继续按原验收要求复验，不从本地页面启动结果推断 GPU、模型或公网部署已完成。
