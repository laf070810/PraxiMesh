# ADR-010：多语言练习、版本项目和自愿公开成果

状态：接受，2026-10-23；联合应用、冻结镜像、HTTPS 和 B1→B2 升级已通过本地验证，见 [B2 验收](../acceptance-b2.md)。方案见 [RFC-007](../rfcs/007-b2-practice-and-sharing.md)，整体范围仍由 [RFC-006](../rfcs/006-complete-product.md)约束。

## 执行契约

Python 函数、JavaScript 函数、Python 完整程序共用固定 CPython/QuickJS WASI bundle。评测器是服务端允许列表；内容不能指定宿主导入路径或上传 checker。编译学员源代码也在 guest 内。联合 receipt 必须覆盖三种契约，任一失败则 worker 不就绪。gVisor 保留历史 Python 函数能力，明确拒绝新增 JavaScript 和完整程序，不回退到宿主执行。

每次函数返回和完整程序 stdout 都经过严格 JSON 解码，拒绝重复键、非有限数、额外正文和结构超限；完整程序有独立语法编译与执行阶段，非零用户退出码不能伪造可信资源分类。限制、真实 stdin、MemoryError 分类和两阶段预算详见[完整程序契约](../stdio-contract.md)。预期答案只在控制器比较。运行耗时包含启动和共享主机等待，不用作公平速度排名。

## 本地工具与凭证

本地公开测试复用经过摘要校验的 WASI bundle，返回 `formal_result: false`。服务端只接受明确版本、源码、Run/Submit 模式和幂等请求标识；客户端不能提交判题结果。不同内容复用同一请求标识返回冲突，相同请求重试不重复扣配额或创建任务。公开包不携带隐藏测试或参考实现。

访问令牌是随机秘密，仅签发时显示，数据库只存摘要。签发需要登录、密码和 CSRF；用途限于本人提交和结果读取，有有效期、数量上限与撤销。身份恢复同时撤销现有令牌。远程传输必须 HTTPS；CLI 只为显式回环开发允许 HTTP，拒绝重定向、URL 凭证及隐式环境代理。下载目录和源码私有，不执行下载脚本。接口与操作见[本地工具](../local-practice.md)。

## 项目与成果

项目计划是维护者发布的不可变修订，每个阶段固定 ProblemVersion 和内容摘要。推荐前置不阻止自由跳转；最终阶段需要真实集成任务及参考解/错解验证。项目完成只来自本人对固定版本的有效正式结果。历史通过保留，当前新版结果不会替代旧阶段；旧阶段不接受新提交，页面指向当前练习并解释区别。Web 对计划表只读，worker 无权限。

公开主页默认关闭，独立填写公开名称，不复制私有资料。每条结果需本人明确分享，关闭主页会撤回已有结果，重新开启不会自动发布。公开投影仅显示审查过的题目/版本、结果计数与策略标识，不公开源码、隐藏数据或主机身份。结果校验由 `core.result_evidence` 同时服务项目和成果展示，核对契约、时间、计数、环境与指纹；它不是接受客户端上报结果的认证机制。

榜单按相同题目版本和评测指纹分组，使用顺序测试通过量，同分同名次；没有跨题总能力榜。专业 ML、科学计算、Agent 和 GPU 指标必须单独审核后才能进入相应展示，不能自动套用本批榜单。

## 翻译与部署

界面使用中英 gettext。题目译文绑定不可变版本，知识译文绑定源内容快照；文字覆盖允许列表不包含代码、输入/预期值、关系或评测规则。没有精确版本译文时明确显示中文原文。快照迁移只保存实际存在的知识内容，不恢复未记录的历史。用户正文和私有内容不自动翻译。

新应用同步覆盖镜像、源码制品、导出/删除与最小数据库授权。首次安装可显式导入目录、译文和项目；升级只迁移 schema，保留当前已发布内容。B1→B2 验收需保留真实私有笔记、社区草稿、代码和正式成绩，实际验证新表权限、令牌提交与旧/新环境结果分享。单元测试、隔离探针和部署证明各有范围，不能相互替代。
