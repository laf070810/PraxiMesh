# ADR-009：私有学习记录与主动公开的社区内容

状态：接受，2026-10-23。设计：[RFC-006](../rfcs/006-complete-product.md)。实际验证结果见[需求追踪](../requirements.md)，本决策不代表整个阶段 B/C 已验收。

`learning` 和 `community` 使用现有 Django 用户、知识节点和不可变题目版本，不新增网络服务。收藏跟随稳定题目 ID；笔记可独立保存，也可绑定一个题目版本或知识节点。阅读记录绑定当时内容摘要，仅表示用户自行标记已读。全部学习数据仅本人可见，并纳入账户导出和删除。

证据摘要只计本人已完成的正式评测，排除公开 Run、排队任务和平台内部错误；历史版本保留但不算当前题通过。领域内按题目去重，跨领域归属显式保留。复习和前置练习建议说明所依据的记录，不显示推测的掌握百分比，不限制用户自由练习。

讨论、问题、题解及评论先保存为私有草稿。作者主动提交后才对具有 `community.moderate_content` 权限的审核者可见；通过后正文和用户名公开，私人显示名称及原提交源码不自动公开。题解必须绑定明确版本。修改已公开内容立即停止公开并进入新一轮审核；作者可撤回或删除。关联题目下线时，相关正文和评论停止公开。

审核以行锁和正文修订号校验，旧页面上的决定不能批准后来修改的内容。审核权限与站点 staff 标记分开，不允许审核自己的正文，也不允许处理涉及自己内容的举报或申诉。举报和申诉只向当事提交者及审核者显示；处理说明不进入公开页面。所有写入口要求登录、POST、CSRF、长度限制和共享数据库限流。正文按纯文本转义显示。

删除账号级联删除其学习记录、社区正文及关联评论/案件。审核事件仅保留目标 UUID、修订号、动作和时间，不复制正文、用户名或作者 ID；审核者删除账号后 actor 置空。事件 ID 是操作追踪依据，不声明所有历史数据都已匿名化；站点备份与日志的保留周期仍由运营者制定。

Web 仅获得新应用明确列出的表的 CRUD 权限；worker 继续只有评测所需三张表的权限。部署控制器根据实际迁移记录检查应有表，并兼容升级前的旧库。迁移记录和实际表不一致时拒绝放行，不能靠对所有表授予权限绕过校验。新增应用包含在冻结源码和镜像中。

代码提供可验证的治理工作流。正式投稿授权、版权要求、审核时限和申诉政策仍需维护者根据 PRD §13 确定，工作流不会自动替代这些决定。
