# ADR-007：持久暂停入口与按评测策略领取任务

状态：接受，2026-10-23。设计：[RFC-005](../rfcs/005-deployment-coordination.md)。

发布协调以数据库事务为入口边界。暂停、恢复与新任务入队使用同一队列锁；暂停 token 持久保存，仅同一 token 可解除。暂停不影响阅读和草稿，不取消在途任务，没有自动到期开放。排空超时或进程中断保留关闭状态；恢复要求当前策略的健康 worker，并拒绝遗留的其他策略任务。

新提交记录 backend、解释器制品与评测策略形成的指纹；worker 按启动时的指纹领取。历史无指纹任务不猜测执行环境。新旧策略可以被可靠区分，但部署仍须排空并停止旧 worker；不是允许任意混跑或零停机 schema 升级的承诺。

不采用 Web 进程内变量、依次修改各副本环境或自动过期锁。这些方式无法同时满足并发入口边界、部署故障时保持关闭和可重试的所有权检查。

首次引入这项迁移时旧进程尚不理解新协议，必须先停止旧入口、排空旧队列、停止旧 worker，再迁移和启动新版本。新命令之后可用于在线暂停；不会自动迁移生产数据库。代理激活、数据库迁移协调与自动恢复 journal 仍待实现。
