# ADR-077：本地 GPU 使用固定控制入口与有界管道协议

日期：2026-11-02。状态：已采用，宿主启动器及硬件验收仍待完成。对应 [RFC-024](../rfcs/024-local-cuda-practice.md) 和 [ADR-076](076-local-gpu-operation-lifecycle.md)。

本地调用不需要应用数据库，但必须进入已经核对原挂载、物理锁和持久状态的可信控制器。新增固定 `scripts/container_practice_entry.py`，复用原控制镜像的完整源码契约；只接受初始化、公开执行和原操作恢复，不增加任意宿主执行命令。

`judge/container_practice_protocol.py` 绑定本次模式、设备 UUID、随机挑战、绝对期限、原状态摘要及当前控制器/执行源码摘要。调用者先核对握手，再发送任务镜像与驱动清单；完整环境匹配后才发送公开问题和源码。执行端调用原二十四阶段生命周期，客户端核对完整有序进度、非正式结果及 EOF。结构身份使用规范摘要比较，避免 Python 把布尔值当作整数；正式 Submit、性能分数及客户端启动报告均不能进入该协议。

`container_practice_transport.py` 复用原帧格式和字节预算，使用独立持有的非阻塞管道描述符，不提供重连或进程启动。取消、断连、额外输入和期限到达终止正常执行；原任务清理继续使用已有独立路径。入口信号处理仅设标志，结果必须晚于原终态保存和最后核对。恢复直接使用原状态，不构造新执行适配器或运行旧镜像。

宿主启动器仍须登记并监督原控制容器，检查容器成功退出并完成回收，不能仅凭 EOF 宣称成功。初始化也不签发就绪凭证。真实管道、文件/锁、信号及无设备镜像检查与 GPU 执行模型分别记录；本决策不表示完整本地 GPU 工具或硬件验收已完成。
