# ADR-015：默认 Compose 包含真实 CPU 评测

状态：接受，2026-10-30；容器验收进行中。依据：[RFC-016](../rfcs/016-compose-selfhost.md)。本决定替代 [ADR-014](014-compose-preview.md) 中默认 Compose 仅提供页面体验的范围。

默认构建 Web 和独立 WASI worker，解释器及其摘要由 Docker 构建中校验过的固定来源产生。Web 只保存摘要，没有 Wasmtime 或执行制品；worker 在自身容器内执行完整探针，健康和策略匹配后接收任务。维持原有 receipt 有效期与所有资源、配额、租约和结果证据规则。worker 到期退出后，由 Compose 重启并重新检查。

保留现有 `app-data` 卷、SQLite 文件和密钥，复用原子初始化及既有库不重导的行为。新入口只接受单机 local 模式；HTTP 的调试详情关闭。选择 SQLite 是为了原页面体验实例直接升级且无需用户迁移数据。生产 PostgreSQL/HTTPS、备份排空和代际恢复仍使用已有发布协调器，不把该入口的验证范围外推。

AI 可接入维护者指定的 HTTPS 服务；`compose.ai.yaml` 则额外构建固定来源的 CPU 模型。模型通过 Web 容器内部回环地址访问，不发布端口，不挂数据库卷；独立凭证卷仅授予 Web 与模型。未选择模型覆盖文件时不下载权重。所有正式成绩仍由独立评测器产生。

构建代理通过 Docker 预定义 build args 传递，不写入运行镜像。下载失败有界重试，摘要或体积不符立即失败，不发布部分文件。保留源码、权重和依赖许可。不同机器的编译结果不承诺逐字节相同，但同次构建的 Web/worker 使用同一制品身份。

验证状态及原始失败见 RFC；GPU、托管 CI 和公开运营门槛继续保留在需求追踪中。
