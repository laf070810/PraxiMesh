# ADR-003：私有身份、分层测试与失败关闭发布

状态：接受。日期：2026-10-22。依据：[RFC-001](../rfcs/001-phase-a.md)。

决定：Django 服务器会话、Argon2 密码、一次性恢复码（仅保存哈希），不采集邮箱。源代码、草稿、历史和进度默认私有，无匿名公开接口。CSRF、模板转义、CSP、数据库限流和有界队列为默认行为。生产自由注册默认关闭，维护者确认运营策略后才开启。

锁文件和自动化检查作为复现依据；应用容器非 root；公开站点由 TLS 代理接入，Web 不挂载 Docker socket。单元/集成、PostgreSQL、真实沙箱安全和浏览器验收各自记录结果；缺少任一核心门槛不能宣布阶段 A 完成。备份恢复和依赖安全升级属于交付内容。

替代：自行签 JWT 无当前收益；OAuth 或邮件恢复增加第三方依赖及个人数据收集，后续独立评估。影响：恢复码需用户妥善保管；公开发布依赖 PRD §13 的非技术确认，内部研发可继续。

2026-10-22 实施补充：IP 限流默认取直接连接地址，只有显式列出的可信代理 IP 可提供其覆盖的单值 X-Real-IP，防止伪造并避免合法用户共享代理额度。PostgreSQL worker 使用仅可读取题目版本和操作任务/健康记录的独立角色，已实测不能读取 auth_user；Web 会话密钥不分发给 worker。部署信任链变化必须重新评估。

2026-10-23 账户核对：用户名限流与 Django 登录采用相同的去除首尾空白和 NFKC 规范化，恢复表单也采用同一规则，防止同账号通过等价写法获得新的尝试额度。草稿按题目版本私有保存；旧版本或已下线题目的草稿仍可分页找到、查看及复制，不自动覆盖当前版本的编辑内容。
