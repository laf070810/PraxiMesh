# ADR-004：基础 Python 函数采用能力受限的 WASI 后端

状态：接受，本地真实隔离与产品闭环已验证；公开部署另行验收。日期：2026-10-22。依据：[RFC-002](../rfcs/002-wasi-python.md)。

阶段 A 的基础函数题采用官方 CPython 3.14.9 的 WASI 构建、Wasmtime 50.0.1。Web、队列和可信比较器保持相同接口。gVisor 保留为显式选择的另一执行策略，本机不具备其条件；失败时绝不自动切换后端。默认配置继续关闭执行。

WASI 只获得只读标准库和当前输入，不授予网络、宿主环境、进程、线程、可写文件或项目目录。每用例创建新的 Wasm 实例和受 OS 限额约束的可信驱动进程。Wasm 线性内存、fuel、table/stack 及宿主 CPU/地址空间、墙钟、文件描述符和输出均有界。驱动有独立 OS 定时器和父进程死亡信号；worker 崩溃不会留下持续运行的任务。

使用带摘要的可信预编译解释器，避免把每次编译的约十秒成本算入学习者预算。该 native cache 只由固定源码构建，随 manifest 固定摘要、运行时及引擎策略，执行前逐文件校验；不接受用户 Wasm 或 native cache。制品目录不允许额外文件、符号链接或组/其他用户写入。引擎策略变化必须重新构建。

代价：此处 Python 不具备完整 Linux 能力或第三方原生扩展，题页明确版本与边界；WASI SDK 24 是该 CPython 发行版构建脚本指定的版本，不是对任意旧 SDK 的通用认可。运行时仍属于可信计算基，必须维护依赖与安全公告；生产 worker 使用独立无业务凭证的账号/节点。

依据包括真实资源/能力探针、参考解、典型错误解、宿主 canary、监督进程故障回收及浏览器 Run→WA→Accepted→进度检查。具体版本、测试数及尚缺项统一见[验收记录](../acceptance.md)。

2026-10-23 补充：[ADR-006](006-release-artifacts.md) 将 bundle 升为 format 2，显式设置 Linux x86_64 target、关闭 component model，并保留固定 SDK 运行库声明。解释器已重新构建并通过真实回归及打包容器内探针；旧格式不再被接受。
