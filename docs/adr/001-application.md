# ADR-001：模块化 Django 应用与版本化内容

状态：接受。日期：2026-10-22。依据：[RFC-001](../rfcs/001-phase-a.md)。

决定：Django 5.2 LTS、Python 3.11、服务器模板与渐进 JS；本地 SQLite，生产 PostgreSQL。内容以受 schema 约束的 JSON 投稿，数据库保存不可变题目版本及内容摘要；导航、知识关系、路径独立建模。显示标题可变，稳定 ID 不变。中文为初版，缺少译文回退中文并注明。

理由：使用框架成熟安全机制，减少自制认证和多端数据契约；无前端编译即可贡献页面；关系和版本在加入新学科时仍可用。替代：FastAPI/SPA、Node 全栈、图数据库，当前复杂度没有对应收益。

影响：内容导入需审核；题目更新必须升版本；SQLite 不支持生产多 worker，生产测试必须覆盖 PostgreSQL。尚不支持自由上传 checker 和富 HTML。以后拆服务保留 ID/版本契约。
