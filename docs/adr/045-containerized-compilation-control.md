# ADR-045：在可信控制容器内发起隔离编译

日期：2026-10-31。状态：接受；十四项真实编译控制场景及七组原控制端兼容回归通过，见 [G29 验收](../acceptance-g29.md)。背景见 [RFC-021](../rfcs/021-gpu-container-supervision.md)。

控制镜像的源码清单包含完整编译契约，由镜像内重新计算固定编译镜像的身份。拒绝依赖宿主计算结果、缺文件时跳过摘要或借用宿主解释器。控制端保持原 UID 映射、私有 socket、共用设备锁和 journal；NVRTC 与源码仍只进入独立任务容器中的 gVisor guest。

新增一次性可信编译调用，固定使用包含运行时开销的 `container-workload-v1` 和 journal v2。请求先验证，开始回调成功后再发送源码；所有出口尝试清理自己的原记录，正常结果只在 guest、外层容器及 journal 完成清理后返回。取消和清理失败不转换成学员编译错误，未知结果、重复调用或记录所有者变化均拒绝。

此接口只提供编译状态和有限产物元数据，不发布题目、成绩或 GPU receipt。其镜像与资源身份用于调用追踪，不充当正式 GPU 环境。容器 GPU 执行、设备监测、完整启动/领取/结算及 Compose 仍须继续实现和验收。开发操作保留在 [GPU 指南](../deployment/gpu.md)，不新增第二套部署说明。
