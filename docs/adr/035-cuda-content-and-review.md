# ADR-035：CUDA 内容校验、候选组合与正常队列验收

日期：2026-10-31。状态：接受。设计：[RFC-019 内容补充](../rfcs/019-gpu-kernel-evaluation.md#cuda-内容与发布补充2026-10-31)。

内容 v1 注册 `cuda-kernel-v1`，Schema 先约束字段，再调用共用 GPU 契约校验形状、可信预期和 UTF-8 源码预算。CUDA 不进入 CPU 分派表，既有 CPU 的语言、用例和容差限制保持原样。无数据库迁移或执行策略变化。

候选扩展只保存新增知识和题目，引用基础包的稳定概念。只读 `content_compose` 将其追加到明确选择的完整包，不覆盖 ID、不写数据库；输出使用原格式并保留同一大小上限。正式导入继续执行全量撤回和不可变版本规则，第三方包继续执行原审核与归属规则。默认目录不包含尚未通过真实硬件验收的 CUDA 内容。

真实解法检查使用普通 API 和现有完整 GPU worker，避免第二套执行器或绕过启动凭证。工具先锁定所有题目摘要，逐项记录幂等请求键，按参考 Run、参考 Submit、错解 Submit、恢复参考 Submit 串行运行。不同环境、缺失正式证据、错误资源状态及不完整性能反馈均拒绝。超时或连接中断后保留任务和私有报告，不自动重发或删除测试站点。

该工具应在独立测试站点和合成账号上运行；操作者负责保留失败站点，确认 worker 清理完成后再关闭。工具不直接连接数据库，也不修改设备配置、运行凭证或发布状态；只通过显式站点的普通提交接口创建任务。报告能记录服务提供的 worker 证据，不能替代隔离、硬件或生产部署验收。
