# ADR-013：在 WASI 内验证类实例与 API 行为

状态：接受；真实 WASI、PostgreSQL、HTTPS 与冻结镜像浏览器均已完成本地验证。日期：2026-10-24。依据 [RFC-013](../rfcs/013-object-api-practice.md)，证据见 [E 验收](../acceptance-e.md)。

新增有界、版本化的 `python-object-api-v1`，使用类构造与声明方法的操作序列验证接口行为。初始任务为有界 FIFO 队列，并在单场景内验证多个独立实例。

固定驱动只在现有 WASI 中运行学员代码，主机保留全部受保护预期并独立比较结果。每场景一个独立 WASI 实例，场景内维持对象状态；继续使用同一份 CPU 资源预约、租约、版本历史和私有学习证据。运行时和内容都不接受可执行插件。gVisor 对新契约明确拒绝。

选择此方式是为了提供真实的库/API 行为验证，同时复用已有产品功能。普通函数模拟操作不能证明类接口，宿主导入学员模块不符合安全边界，多文件/原生扩展需要另外设计。新增代码和探针进入策略摘要，正式交付必须重跑真实执行门槛及浏览器流程。
