# ADR-011：专业实践、机构内容与私有学习规划

状态：接受，2026-10-23；C 本地联合验收通过，范围见 [C 验收](../acceptance-c.md)。方案见 [RFC-008](../rfcs/008-personal-blogs.md)、[RFC-009](../rfcs/009-organizations-and-packages.md)、[RFC-010](../rfcs/010-specialist-evaluation.md) 和 [RFC-011](../rfcs/011-intelligent-learning.md)。维护者选择先交付可本地验证的自部署版本，真实 GPU、公开运营与项目许可证留待后续。

## 专业实践与资源

采用三个固定 CPU/WASI 契约。ML 提交训练函数，控制器只交付训练集，并在隔离于学习者程序的留出数据上计算 MSE/MAE；科学计算提交参数和协方差，控制器独立检查加权直线拟合、正规方程残差及数值容差；Agent 在固定账本工具中分轮交互，控制器检查访问轨迹和最终整数汇总。三者复用题目版本、私有源码、Run/Submit、队列租约、本地工具和本人进度，不能通过内容包安装任意 checker。

运行时、可信控制器和探针共同进入评测策略摘要。当前完整启动门槛为 123 个实际探针，包含专业参考解、错解及 Agent 的输出、状态、调用、时间和父进程退出边界。失败时不接收新任务。GPU、网络 Agent、原生扩展或大规模模型训练需要另行设计和实际环境验收，当前不提供这些执行能力。

资源政策 `cpu-invocations-v1` 按测试或 episode 的最大调用次数预约，每账号默认每 UTC 日 120 单位。它不代表实测 CPU 秒或费用。幂等请求只预约一次；第一段用户代码启动前由有效 worker 租约消费；只有可信的执行前平台失败可以释放。迁移前记录保留为零单位 legacy，不追溯收费。Agent 每轮续租，任务取消后不再启动下一轮。

`verified_evidence` 统一核对正式记录的版本、语言、契约、环境指纹、资源状态和结果结构，供学习、项目、课程与规划使用。专业反馈保留各自指标；隐藏场景不公开训练数据、参考参数或轨迹。既有 `verified_metrics` 只处理普通顺序测试的公开榜单，专业指标不混入普通题目排行。

## 机构内容与公开投稿

博客沿用私有草稿、主动送审、独立审核、编辑后重新审核、撤回和删除流程。公开主页不会自动发布博客，也不把私有用户名复制为公开名称。

组织区分 owner、instructor、learner；邀请绑定目标账号并须本人接受。课程修订固定题目版本，教师可维护课程，但不能读取他人私有源码、结果或学习证据。最后一名 owner 不可自行离开；恢复由可信管理命令完成。

第三方题库有组织命名空间、明确来源与授权声明、不可变修订和摘要。独立于组织成员的审核者批准指定摘要，随后由可信管理命令发布或撤回。审核声明不自动等同法律授权或参考解已执行：维护者仍须验证内容来源以及真实正确/错误程序。Web 可管理申请和审核，不能写正式知识/题目表；worker 无组织表权限。

官方目录与第三方包共用发布锁。官方完整导入只管理官方归属，不撤回组织拥有的对象。已撤回对象仍保留归属，防止命名冲突或接管。历史课程和题库修订不因账号删除丢失；删除个人成员关系、收到的邀请和选课记录，并清空保留机构记录中的个人作者关联。账户页面提前解释这一边界，导出仅含本人数据。

## 规划与可选 AI

私有目标和练习计划由公开依赖图与本人有效正式记录生成，固定源摘要与题目版本；用户可以跳过、恢复或关闭建议。多维证据最多检查最近 500 条正式结果，明确范围，区分不同题目、旧版本和近期失败；不把单次通过转成掌握百分比。

AI 默认关闭。启用后每次先展示输入预览，再由本人确认发送。输入只含公开题意、问题、主动选中的作者提示，以及明确勾选后手动粘贴的源码。不会自动读取草稿、隐藏测试、参考解或他人数据。端点、模型、凭证和提供方说明由维护者固定，只传给 Web。

传输在独立受限进程中完成，HTTPS 验证证书，无代理、重定向或工具调用，20 秒硬截止，响应和正文有界。幂等请求、每日用量与全局并发在数据库事务内预约；执行租约独立于账号和正文，删除历史或执行中删除账号不能绕过并发、重置日用量或复活已删除内容。模型文本转义展示，不写成绩。

本地 CPU 模型实际接入证明推理链路可用，同时保留了错误统计解释的失败样例。它不构成模型质量保证；默认关闭和明确预览仍是交付设置。配置、固定制品及有界重放见 [模型指南](../local-coaching.md)。

## 部署验证

新增 migration、角色授权、镜像复制范围、源码档案、导出/删除和升级保留检查一起交付。首次安装可显式导入示例目录；升级只迁移数据库结构，不自动发布新题或机构内容。实际 PostgreSQL 回归、冻结镜像首次安装、B2 数据保留升级、HTTPS 浏览器与性能检查分别提供证据，不能以应用单元测试替代部署结果。
