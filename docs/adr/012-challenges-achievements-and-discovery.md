# ADR-012：固定版本挑战与私有实践成就

状态：接受，2026-10-24；本地 PG、HTTPS、冻结镜像及 C→D 升级通过，见 [D 验收](../acceptance-d.md)。方案见 [RFC-012](../rfcs/012-challenges-achievements-and-discovery.md)。

活动采用独立身份、不可变修订、题目版本绑定及本人参与记录。维护者通过有界 JSON 管理命令发布；Web 对三个定义表只读，只能写参与表；worker 无权读取四张表。UTC 起止时间属于不可变修订，唯一参与约束与账号行锁保证重复或并发加入不重置时间。退出删除参与，重入从新的时间统计。

完成证据必须由可信正式评测产生，属于本人、匹配固定题目版本，且提交和完成均位于活动窗口并不早于加入。Run、异常/不完整结果、其他账号/版本、过期或未来结果不计数。题目下线隐藏相应内容和进度；归档版本只读，不能通过活动入口绕过提交准入。

成就从本人有效结果、固定项目阶段与活动进度推导。规则与证据数量公开说明，个人结果保持私有；重复提交、同题不同版本及同一项目/活动的多个修订不刷量。不建立永久奖励表或证书，失效/撤回的证据会影响当前展示。导出包含本人参与摘要和规则结果；删除账号级联清除参与，保留维护者的活动定义。

题库筛选从实际发布契约产生类型、运行条件、库要求、当前后端兼容性和预约单位选项。兼容性不冒充 worker 实时就绪，不能执行的题目仍可阅读和保存草稿。不存在的 GPU/外部库能力不进入选项。

首次真实 PostgreSQL 验收发现初始参与唯一约束与表同名；在发布前改为独立约束名称后，新数据库上的 212 项功能/权限/并发检查通过。SQLite 检查不能替代该验证。冻结镜像、HTTPS 浏览器和 C→D 升级已分别留存实际回执。
