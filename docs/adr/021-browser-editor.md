# ADR-021：站内渐进编辑器与本地静态分析

日期：2026-10-30。状态：接受。设计：[RFC-020](../rfcs/020-browser-editor.md)。

采用 CodeMirror 6 增强现有 textarea。保留 Django 表单字段、私有草稿、Run/Submit、评测离线与限额门槛；编辑器失败仍保留文本框。Python 使用 Ruff WASM，JavaScript 使用 Prettier 的固定浏览器解析器，在同源 worker 内进行检查和格式化，不执行源码或获取用户配置。异步结果绑定文本修订，格式化是一笔可撤销编辑。

依赖锁定后构建并提交站内资源、摘要和许可证；部署不连接 CDN 或增加 Node 服务。CodeMirror 共用单份状态模块，构建时拒绝重复实例。CSP 使用每次响应的样式 nonce，仅练习详情允许 WASM 与同源 worker，不启用任意 JavaScript eval。

组织和辅导页面共用内容容器；筛选表单用网格保持同排控件底边一致，手机题目列表把难度与状态放在正文下方。复选和单选控件使用独立宽度与文本对齐，不套用普通文本输入框的满宽规则。

浏览器验证覆盖中英、桌面/平板/手机、源代码同步、真实本地解析/格式化、撤销、快捷键、资源失败及无 JavaScript 回退。该改动不改变评分规则、内容版本或 GPU 评测准入。
