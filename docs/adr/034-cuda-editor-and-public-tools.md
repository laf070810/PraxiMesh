# ADR-034：CUDA 编辑、公开包与独立资源显示

日期：2026-10-31。状态：接受。设计：[RFC-020 补充](../rfcs/020-browser-editor.md#cuda-编辑与资源显示补充2026-10-31)。

CUDA 复用既有 CodeMirror 表单、私有草稿、修订保护与同源 worker。通用 C++ 语法会误报 `__global__` 等设备限定符，因此在构建时扩展锁定的 Lezer 语法；保持上游字符串、注释、预处理器和生成的 token ID 一致，不删除或替换用户代码。结构提示只作警告，不冒充 NVRTC 类型检查。使用锁定的 clang-format WASM 格式化固定 `solution.cu`，不读取用户配置、不执行源码、不外发源码。

CUDA 公共数据沿用 API v1 和 `scripts/practice.py`，下载私有 `.cu` 文件，校验固定操作、入口、浮点容差、输入形状与公开答案。公开包拒绝其他执行契约、可见性覆盖及私有字段；当前本地 `test` 明确拒绝 CUDA。远程 Run/Submit 沿用现有身份、令牌、幂等与准入规则，不新增执行回退。

题库显式标识 CUDA/NVRTC/gVisor 与设备内置函数；GPU 兼容状态来自既有只读健康准入，每次页面生成共享一次查询结果。CPU 调用单位与 GPU 整卡秒数各有筛选字段，填写任一字段仅匹配相应资源类别，同时填写两者无匹配。GPU 秒数仍为预约量，不是内核测量时间。

上述功能可在不占 GPU 的情况下验证。默认题库、设备允许列表、评分策略和已发布版本不变；正式 CUDA 内容、完整硬件验收、容器部署及本地 GPU 执行仍需独立完成。浏览器验收使用自有临时数据库中的合成题目，并验证中英布局、补全、格式化撤销、键盘退出、私有草稿和故障回退。
