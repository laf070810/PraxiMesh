# G14：完整启动编排、私有凭证与就绪事务

日期：2026-10-31。设计：[RFC-019](rfcs/019-gpu-kernel-evaluation.md#正式就绪检查)、[ADR-030](adr/030-gpu-complete-startup-and-receipts.md)。遵循维护者继续不占 GPU 的要求。

## 实现

启动接管与物理恢复、资源检查、十九项 CUDA 用例、三项控制器故障已连接为二十四个必需阶段。各阶段最多 180 秒，整体最多 4320 秒；部分报告、CPU 模式、缺失清理或恢复不能生成凭证。设备保持隔离停用及原预约，直到私有凭证重新读取通过，并在有界事务中再次核对设备行后确认恢复。

凭证绑定完整集合、证据摘要、执行环境、worker、当前锁所有者和主机启动身份，最长有效 24 小时；双时钟与完整任务余量均须满足。目录/文件权限、类型、链接数、替换和内容大小严格核对。新进程不能复用旧文件跳过检查。空闲心跳另行核对实际设备，并在同一行锁下核对身份和刷新健康。

正式 worker 与 Web 准入尚未调用该入口；本轮没有创建实际 GPU 运行凭证或改变用户数据库中的设备状态。
