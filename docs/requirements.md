## 跨模块要求与最终门槛

- PRD §2–3：Learn/Practice 独立完整；分类、依赖图、路径独立；共享概念、别名治理、跨领域与多维筛选持续成立。
- PRD §4–5：各题型都有独立任务/样例/约束/学习目标/资源声明/版本/提示，真实且可追溯评测，隐藏测试/他人源代码不泄露；多指标和环境信息按实际语义展示。
- PRD §6–7：自由学习、选择参与路径/排名/社区；只从适当证据推断能力；默认私有，用户主动公开、可撤回；贡献可校验、审核、修订、撤回和追踪。
- PRD §8：可维护依赖、自动化成功/失败/安全/恢复测试、可复现部署；密钥/权限/网络/CPU/内存/存储/额度约束；安全报告流程；键盘/移动阅读/清晰空态和错误；实测性能和成本政策。
- AC-01–07：旧闭环在每批扩展后持续成立；AC-08 需用真正不同的评测方式证明复用现有知识、题库、账户与进度。
- PRD §12：重大方案先留 RFC、决定更新 ADR；实现与证据同步；整体完成必须覆盖本表全部行及跨模块门槛。
- PRD §13：名称/品牌、各类许可证、运营与注册、资源政策、治理条款和隐私地域仍待维护者明确；公开仓库/实例的实际目标未提供。保留为整体目标待办，不把本地代码实现当成这些事项已经落实。
