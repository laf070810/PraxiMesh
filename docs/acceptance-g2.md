## 验证边界

超出整卡容量的分配失败与设备堆限制是两项不同检查；本次没有证明任意较小的每任务显存配额，也没有对共享 GPU 提供资源分区保证。显存必须结合明确的整卡预约和时间预算定义，不能把 CPU cgroup 的内存限额当作 GPU 显存限额。

还需把这些边界接入正式执行策略、不可伪造的启动检查和 GPU worker；补齐编译 CPU/内存/PID/输出限额、持续采样、数据库预约争用、取消/失联、设备隔离停用、可信性能以及真实页面/部署验收。单个正常退出或受控 KILL 的成功不能替代所有失联路径的恢复证明。
