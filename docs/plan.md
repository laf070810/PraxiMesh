# 阶段计划

修订：2026-10-23。阶段 A 尚未完成。

## 阶段 A：最小完整闭环

游客从领域、主题、概念、教程或路径进入练习；账号用户保存私有草稿，运行公开示例，提交 Python 函数，在安全 worker 上得到真实结果，查看自己的历史和路径练习进度。教程从不成为提交的前置授权条件。所有界面先提供中文，概念 ID 不依赖显示语言。

1. **A1 基础与内容**（R-01–04、08、10）：应用骨架；跨领域概念与类型化关系；独立教程；带顺序的路径；题库搜索/筛选；内容 schema、引用与前置 DAG 校验；不可变题目版本。先精审 8 道题，质量稳定后扩充至建议的 15–30 道，不用数量代替审核。
2. **A2 私有练习**（R-05、07）：注册/登录/退出/恢复码；私有草稿、个人资料、历史、导出与删除；CSRF、越权及限流测试。
3. **A3 真实判题**（R-06、07）：数据库任务队列，公开运行与正式提交分开；独立 worker；WASI 逐用例隔离，保留独立选择的 gVisor 策略；可信控制器比较结果；AC/WA/语法/运行/时间/内存/输出超限/平台故障；租约和故障回收。
4. **A4 验证和可交付部署**（R-09、10）：锁定依赖、容器、CI、TLS、健康检查、备份恢复演练；真实沙箱安全回归；浏览器核心流程；按 AC-01–07 留存证据。

## 必须通过的安全发布门槛

- 未配置评测或 worker 不健康时，内容、登录和草稿可用，提交返回明确的 503；没有宿主执行、普通容器或客户端上报通过的后备路径。
- 工作节点使用经过真实验证的显式隔离策略。WASI 固定解释器、标准库和运行时，只授予只读标准库与有界输入输出；fuel/内存/宿主进程预算有效。gVisor 必须有 runsc 和有效 cgroups。两者均非 root、无 guest 网络/业务凭证、可终止及回收，无自动后备路径。
- 真实隔离测试验证正确/错误/语法/异常/死循环/内存/输出、网络拒绝、文件与凭证隔离、子进程限制、故障分类、清理；模拟测试不能替代此项。
- 隐藏测试预期值留在控制器；单次只提供当前输入；隐藏输出、异常文本不回传；仅服务端比较结果可产生 Accepted。
- 身份恢复、CSRF、跨账户隔离、XSS、限流、队列上限、失联恢复验证通过；所有用户源代码默认私有。
- 生产配置无 DEBUG、随机密钥、TLS、安全 cookie、正确代理边界；依赖审计与升级机制；备份恢复通过；新环境按文档可复现。
- PRD §13 的品牌、代码/内容许可、运营模式、资源额度、治理、隐私地域由维护者在公开发布前确认。技术开发继续，不代替维护者作法律或运营承诺。

## 后续阶段

B：扩充内容与路径、收藏/进度分析、第二种 CPU 评测、可撤回的题解/讨论/举报审核及可比较榜单、中英内容。C：GPU/ML/科学计算/Agent 资源池、第三方专题库。都复用知识、题目身份、版本和用户系统；独立 RFC 决定指标、安全和成本。当前不一次性实施 P1/P2。
