# 公开作品与分组成绩榜

做题和学习记录默认私有。参与榜单需要先开启公开主页，再逐条预览并确认分享正式结果；开启主页本身不会公开提交。入口在网站的“作品与榜单”。

## 分享与撤回

1. 在“公开主页设置”中填写公开名称和简介，确认公开用户名。它们独立于私人账户资料。
2. 从正式结果页的“选择公开这条评测结果”，或“管理我的分享”进入预览，检查指标、版本和公开范围，再确认分享。
3. 在“管理我的分享”撤回单条结果，或关闭公开主页并撤回全部结果。撤回后公开详情、主页和榜单立即停止显示；重新开启主页不会重新分享。

源码、草稿、笔记、受保护测试和其他私人提交不会随成绩公开。分享可以撤回，但无法收回访客此前保存的副本。社区正文有独立的公开与撤回流程，见[社区指南](community.md)。本人数据导出包含分享状态和指标范围；删除账号会删除其分享。

## 如何比较

每个榜单只比较**同一题目版本、同一完整评测环境指纹**。旧题目版本单独分组；题目下线后停止公开。统计范围是所有仍公开的记录，每位参与者只取主动分享的最好成绩，私有结果不参与选择。没有跨题型的综合总榜。

| 指标 | 可分享的正式结果 | 排名依据 |
| --- | --- | --- |
| 顺序测试进度 | Python 函数、完整程序、类/API 和 JavaScript 函数的可核对 Submit；可包含未全通过的结果 | 已通过用例数越多越好；总等待时间不参与排名 |
| GPU 批次计时 | 完整正确、计时与持久证据一致的 CUDA Submit | 批次往返时间中位数按十进制四舍五入至 **0.001 ms**，越小越好 |

相同显示分数并列，之后跳过相应名次，例如 `1、1、3`。GPU 原始中位数 `2.3455 ms` 和 `2.3456 ms` 均显示 `2.346 ms`，因此并列。`0.000 ms` 表示低于显示精度，不代表耗时为零。公开 Run、平台故障和无法核对的记录不能分享；ML、科学计算与 Agent 的专业指标暂不进入这些榜单。

GPU 预览同时展示正确性计数、预热批数、采样批数和每批重复次数；不公开原始采样、编译耗时、设备 UUID、型号、驱动或主机详情。环境指纹只用于识别可比较的分组。已有分享保留原公开范围，升级不会自动公开新的 GPU 指标。

## GPU 计时的适用范围

此时间包含控制通信、缓冲区处理和同步，不能当作纯 CUDA 内核耗时或跨设备加速比。固定输入、设备状态、主机负载及多次尝试都会影响结果；它提供同条件下的练习反馈，不能证明掌握程度或替代严格基准测试。

GPU 分享与榜单的页面、规则和权限已完成非 GPU 验证；**完整 GPU 执行路径和正式题型尚未验收，默认网站不开放 GPU 提交**。运行条件与部署进度统一在 [GPU 部署指南](deployment/gpu.md)，本次验证范围见 [G20](acceptance-g20.md)。
