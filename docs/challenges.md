# 挑战活动、成就与题库筛选

挑战是自愿参加的限时练习活动。无需参加活动、公开成绩或建立公开主页也可正常练习。参与记录、活动进度和成就均只对本人显示；不会自动创建榜单条目、证书或公开奖章。

## 参加与计数

进入“挑战活动”，阅读时间、规则和固定题目版本后选择加入。可以提前加入，任务顺序自由。只计入本人在加入后、活动窗口内提交并完成的可信正式通过。开始时间包含在内，结束时间不包含在内。Run、服务错误、其他版本和其他账号结果不计入。

退出删除加入记录；重新加入从新的时间统计，之前的正式提交仍保留在本人历史中。活动修订更新不会移动已有参与记录，可从“我的挑战”进入原修订。已结束活动仍能阅读和正常练习；晚于活动结束的提交不会改变本次进度。归档题目只读，练习当前版本不会替代固定版本。题目或活动撤回后暂停显示相应内容与进度。

“我的成就”按明确规则展示首次正式通过、不同题目数量、不同评测契约、完成项目与完成挑战。重复提交及同题不同版本不会增加不同题目数。同一项目或活动的多个修订也只计一次。它反映当前可访问内容上的可信实践事实；内容下线、结果失效或退出活动可能改变展示，不表示知识掌握度。

## 自部署维护者发布

使用数据库 owner 的管理环境运行命令，Web 和 worker 无权发布。示例 `content/challenges.json` 固定在 2026-01-01 至 2027-01-01 UTC，包含两道入门任务。它是有明确日历边界的活动，不会在过期后自动延长。首次安装显式选择演示内容时一并导入；后续升级不自动改写现有目录。

```sh
python manage.py challenge_import content/challenges.json --check
python manage.py challenge_import content/challenges.json
```

制作自己的 JSON 时，设置独立活动 ID、递增修订号、标题、说明、规则与 `YYYY-MM-DDTHH:MM:SSZ` 格式的 UTC 起止时间。每个修订有 1–30 个不同任务，各自绑定已发布题目的 ID、修订号和完整摘要。字段结构见示例；仅导入声明数据，不执行代码。同一修订不可改变，任务绑定也必须完全一致。文件大小上限 1 MB，重复 JSON 键、非有限数、未知字段与不匹配的题目摘要均拒绝。整个包出错则回滚；未列入包的已有活动保持原状。

撤回需确认当前修订摘要，防止误撤回已更新的内容：

```sh
python manage.py challenge_withdraw ACTIVITY_ID --expected-digest CURRENT_REVISION_SHA256
```

撤回保留定义与本人历史；用户仍可从“我的挑战”退出已撤回活动。账号导出中的 `learning.challenges` 包含本人的活动 ID、修订摘要与加入时间，`learning.achievements` 包含当前规则标识、证据数量和状态；不包含他人记录或隐藏测试。删除账号级联删除其参与记录。

## 按实际环境选题

Practice 的题型选项来自当前发布目录，包含普通函数、完整程序、ML、科学计算和 Agent 契约。运行条件、库要求、环境支持情况及正式提交预约单位可组合筛选；搜索继续覆盖标签与中英文名称。预约单位是可信评测调用次数的上界，不是运行时长或成绩。它包含正式评测调用，但不会暴露隐藏测试的输入和答案。

“当前环境支持”表示所选评测后端支持该契约，不代表 worker 此刻已就绪。环境不支持或评测暂停时，阅读与草稿入口仍然可用。筛选只展示目录实际提供的运行条件，不声明尚未接入的 GPU 或第三方库。

实现约定与验收范围见 [RFC-012](rfcs/012-challenges-achievements-and-discovery.md)。真实 GPU、公开运营和许可证仍按[需求追踪表](requirements.md)保留为后续事项。
