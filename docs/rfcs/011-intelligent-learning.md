# RFC-011：有依据的学习规划与可选 AI 提示

状态：已实现，C 本地联合验收通过，具体边界见 [C 验收](../acceptance-c.md)，2026-10-23。覆盖 PRD R-18；不替代客观评测，也不把规则推荐称为模型推理。

## 学习规划和证据

用户自选最多八个已发布概念作为私有学习目标，可随时修改、跳过、关闭。规划从当前题目和明确的知识前置关系生成，说明每个建议的依据；不会把系统建议变成解题准入要求。计划保留所看到的目标身份和版本，但已撤回内容不继续显示正文。

证据只来自本人有效的正式评测，统一复用经过契约校验的结果投影。按领域、概念和自选目标呈现不同题目数量、题型、难度、最近结果及版本范围，保留已通过后再次失败与长期未练习的事实。重复提交同一道题不能增加题目多样性，不把 Accepted 次数、阅读声明或一次通过换算成掌握百分比。Run、内部失败和无可信结果形状的旧记录不计正式能力证据；历史记录仍可单独查看。

结果诊断引用本人可见的公开用例和可信错误类别，并给出可验证的下一步建议；隐藏测试只能用现有脱敏摘要，不反推隐藏输入或声称知道用户思维错误。已有作者提示保持分层、默认折叠和主动查看。

## 可选模型服务

AI 功能默认关闭。只有维护者配置固定服务地址、模型身份、资源上限和公开的提供方说明后才能启用。首次实现可以连接自部署 CPU 推理服务；远程 HTTPS 服务是同一受约束适配器的可选配置。接口、模型和提示版本均记录到回执；真实运行验证与部署目标验收分开记录。

用户每次明确请求提示。页面先展示将发送的题目公开说明、问题、已主动查看的提示层级，以及可选的本人源码片段；源码默认不发送。最终请求只能包含这份预览的内容。隐藏测试、参考实现、其他用户记录、账户秘密和服务器路径不得加入模型上下文。服务地址和凭证由维护者配置，用户不能指定 URL、模型、headers 或工具。

模型仅返回长度受限的文本建议，不具备代码执行、网络工具、文件工具或写成绩能力。输出按不可信纯文本转义，禁止执行或直接渲染 HTML；提示其可能出错，正式结果仍以可信判题为准。系统指令要求先给概念提示和检查步骤，避免直接给完整解法；不能将这一提示词当作绝对的防泄漏保证。

采用固定版本的 Chat Completions JSON 契约即可兼容本地服务，无需依赖任一托管提供方。请求有独立硬截止时间、请求/响应字节界限、固定输出 token 上限，禁止重定向和环境代理继承；生产默认 HTTPS，显式开发配置只允许数字回环 HTTP。异常输出、断连、超时和非成功 HTTP 均显示辅导不可用，不生成假建议或判题结果。

## 配额、并发与私有记录

全局并发槽和每用户 UTC 日配额在数据库原子预约；同一幂等请求只预约一次。请求尚未外发时可释放，已外发或结果不确定时保守计入预算。默认单实例并发一、每用户每日五次，均为维护者可配置的开发默认值而非公开运营政策。

AI 请求和响应默认私有，纳入本人导出与删除。删除一段会话不重置当日调用计数；独立的最小用量记录不含正文。账号删除级联清除私有记录。任何请求正在执行时账号或会话被删除，都不能重新创建已经删除的正文或用户。服务不可用不影响阅读、普通提示、学习规划或判题。

## 验证计划与当前边界

必须测试跨账号访问、CSRF、固定地址/重定向拒绝、严格 JSON、响应超限、超时、模型输出转义、秘密上下文排除、双请求预约、异常释放、配额跨日、导出和执行中删除。测试替身只能用于这些失败和权限边界，不能证明 AI 辅导已可用。

真实 AI 证明使用公开合成练习问题和固定模型制品，检查实际产生提示、无客观分数写入，并记录人工审阅的准确性与局限。已在独立目录使用 Qwen 官方 `Qwen3-0.6B-GGUF` 的 Q8_0 制品及 CPU-only llama.cpp 完成真实推理和一次 Chromium 提示闭环；AI-off 浏览器流程也通过。一个独立方差解释样例出现概念错误，保留失败记录，不把少量通过样例当作可靠性保证。完整版本和运行边界见 [本地辅导指南](../deployment/ai.md)；冻结镜像与升级联合验收另记。

参考：[Qwen 官方模型](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF)、[llama.cpp 官方 CPU 构建](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md)、[官方服务接口](https://github.com/ggml-org/llama.cpp/tree/master/tools/server)。固定源码与模型摘要保存在独立验证目录；此方案不使用 GPU，也不发送真实用户内容。
