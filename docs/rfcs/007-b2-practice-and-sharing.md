# RFC-007：多语言练习、本地工具、中英界面与公开作品

状态：实施中，2026-10-23。上接已验证的 B1，[完整范围](../requirements.md)保持不变。

## 执行与完整程序

第二语言选择固定 QuickJS 解释器编译为 WASI。解析、字节码编译和执行均在 Wasm 内；发布阶段才编译可信解释器。当前宿主 Clang 不构成处理不可信 C 源码的隔离边界，因此这一批不开放 C/C++ 编译。[QuickJS 官方手册](https://bellard.org/quickjs/quickjs.html)、[LLVM 安全边界](https://llvm.org/docs/Security.html)。

采用一个 Python+QuickJS 的 format 3 bundle、一份联合隔离 receipt 和现有全局 worker fingerprint。任何运行时验证失败使整个 worker 不就绪；不采用未绑定身份的额外解释器目录。既有 Python 字节、历史结果和已发布题目不重写，新政策重建缓存和 manifest。用户不能上传预编译 QuickJS 字节码或 Wasmtime cache。[Wasmtime 缓存信任要求](https://docs.wasmtime.dev/api/wasmtime/struct.Module.html#method.deserialize)。

JavaScript 函数题通过 C API 解析有界 JSON、编译源代码、调用明确的全局函数。只接受同步 JSON 值；拒绝非有限数、不安全整数、undefined、BigInt、Promise、循环结构和过深输出。不能用 stringify 静默丢弃值或变成 null。控制器仍独立比较受保护预期值；运行时内不包含答案、数据库凭证或网络权限。语法、运行时、栈、内存、输出和 fuel 限制均须实际验证，不把原型探针当产品通过。

完整程序是独立 evaluator 和内容契约：测试输入为有界 UTF-8 stdin，输出为有界 stdout，整份程序在 guest 中执行。Python 与 JS 的函数题不能冒充完整程序。JS 如提供 readline/print，只读当前用例输入缓冲区，不开放宿主文件或 Node API。工程项目把多个可独立检验的阶段连接到既有版本题目，最终阶段包含真实集成契约；进度来自正式结果，不来自手动勾选。

## 本地公开练习和提交

提供稳定 API 和命令行工具：下载明确版本的公开任务与公开测试、在已校验本地沙箱中运行、提交到可信服务、查询本人结果。下载包不包含参考实现、受保护用例或答案。当地公开测试通过不计为服务端正式通过。客户端声明分数、状态或结果均不接受。

CLI 使用用户主动签发、可撤销、有期限和用途限制的随机访问令牌；数据库只存哈希。令牌只授予本人结果读取和练习提交，不授权账号管理或内容发布；继承现有队列/额度/版本检查。HTTPS 为远程目标默认要求，HTTP 仅显式回环开发；凭证不放 URL、不打印、不持久化到下载任务。浏览器继续使用会话和 CSRF。CLI 不执行下载的构建脚本，也不调用宿主解释器运行学员程序。

## 中英界面和内容

使用 Django gettext、同源 JS catalog 和 POST/CSRF 语言选择，保留当前 URL，避免改变账户限流与权限路径。界面语言与用户文本分开；不自动翻译私人代码、笔记或社区投稿。按稳定 verdict 在 Web 展示翻译，不重写已保存的判题标签或修改安全策略摘要。

题目译文绑定不可变 ProblemVersion；知识译文绑定新增的原文摘要快照。快照迁移只回填现存内容，不声称恢复未保存的过去版本。译文仅覆盖明确的公开文字字段；不能改变关系 ID、参数、预期值、代码或评测规则。源版本不匹配时拒绝导入，缺译时按对象明确显示中文回退。阅读标记继续比较原文摘要。Web 对译文表只读，发布由可信维护命令执行。

## 自愿公开的作品和榜单

新增独立公开资料与结果分享记录，默认关闭；不用现有私密 display_name 自动填充。用户明确选择自己的已结束正式结果后才可展示；不公开源码、笔记和其他账号内容。关闭公开主页、撤回结果、删除账号和题目下线即时撤除相应公开展示。社区正文有独立公开同意，不随主页切换擅自改变。

榜单按题目版本和 evaluation_fingerprint 分组，只使用该契约实际产生的客观指标，同分同名次。共享主机没有验证 CPU quota，故 elapsed_ms 不作为公平性能排名依据。不要把不同题目、ML 质量、GPU 时间和通过量合并为总能力分；后续专业题型另行定义可比环境和指标。

## 集成与验证

在 B1 冻结源码的独立工作副本中并行实现运行时、i18n 和公开作品，按文件差异合并，不覆盖其他已验证改动。新应用迁移、账号导出/删除、最小数据库权限、镜像源码范围及文档同步更新。联合 runtime 的真实双语言正确/错误/恶意程序、浏览器语言切换、翻译泄露边界、令牌范围、项目进度和可比榜单是独立验收项。既有 18 道 Python 题与 B1 权限、升级行为持续回归。
