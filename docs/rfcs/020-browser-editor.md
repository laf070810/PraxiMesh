# RFC-020：渐进增强的练习编辑器与页面对齐

状态：接受，决策见 [ADR-021](../adr/021-browser-editor.md)。日期：2026-10-30。维护者要求补齐语法高亮/检查、常用快捷键、格式化和代码补全，并检查网页标题列表、选项列表等排版问题。对应 PRD §5 与 §8.4；不替代真实评测或改变默认私有草稿。

## 编辑器

在 Django 模板原有 textarea 上渐进增强 CodeMirror 6，覆盖当前 Python 和 JavaScript 题型，保留表单 source 字段与现有草稿/Run/Submit 接口。加载失败或禁用 JavaScript 时继续可编辑与提交。全部依赖按 npm 锁文件构建为站内静态资源，发布包和 Compose 直接带预构建资源，不要求部署者另开 CDN 或运行 Node。

提供高亮、行号、当前行/括号提示、自动缩进、括号补齐、文件内/内置名称补全、查找替换、撤销/重做、注释与行移动。Tab 缩进，Esc 后 Tab 可离开编辑区；Ctrl/Cmd+S 保存私有草稿、Ctrl/Cmd+Enter 运行公开样例，格式化提供按钮与 Shift+Alt+F。所有动作保留明确标签和可见状态，未登录或 worker 离线时保持原有能力门槛。

Python 检查和格式化在站内 Ruff WASM worker 中完成；JavaScript 使用固定 Prettier 浏览器版本及解析器。仅静态解析，不执行学员程序、不把源码发送给外部服务。编辑提示是辅助，真实评测仍由已有隔离 worker 完成。异步检查与格式化绑定当前文本修订，过期结果不能覆盖用户新输入；格式化作为可撤销编辑，长度上限保持 20000 字符，检查失败不清空代码。

## 浏览器边界

CodeMirror 动态样式使用每次响应生成的 CSP nonce，不放开任意内联样式或 JavaScript eval。仅练习编辑页面允许站内 worker 和固定 WASM 工具所需的 `wasm-unsafe-eval`；其他页面保留既有策略。依赖源码、锁文件、许可证和可复现构建入口随仓库交付；新文档/构建文件不能成为旧发布清单的必填项。

## 排版与验证

先检查实际页面，再修复确认的问题：主要导航、页面标题和操作区、知识/题目列表、筛选表单、单选/复选项及移动端换行。保持同一套页面结构，不将布局修复扩成无关视觉重做。

使用一次性数据库、合成账号和回环服务，验证中英编辑、快捷键、补全、诊断、格式化与撤销、异步冲突、草稿重新打开、无 JS 回退、CSP 与资源失败回退；检查桌面/窄屏页面无溢出、控件对齐、键盘可离开编辑器。重放原浏览器练习流程及相关权限测试；截图和日志仅放 `test-results/`。GPU 工作负载仍不执行，完整 GPU 目标保留。
