# RFC-013：有状态 Python 库/API 实践

状态：真实 WASI、PostgreSQL、HTTPS 与冻结镜像浏览器均已完成本地验证，2026-10-24。证据见 [E 验收](../acceptance-e.md)。依据 PRD §4.2、R-12 与 AC-08。既有函数、完整程序和工程项目已经实际运行，本次补充类实例、多次方法调用和接口异常的独立契约。

## 用户可见契约

新增 `python-object-api-v1`，学员提交一个 Python 类。题目明确类名、构造参数数量、公开方法及参数数量、允许的异常，以及返回值和状态变化。初始练习为有界 FIFO 队列：构造容量，`put`、`get`、`peek`、`size`；验证容量边界、空队列异常、重复使用和多个实例独立性。只声明功能兼容性，不从有限用例推断渐近复杂度。

每个场景包含有序的构造和调用操作，可有最多八个实例、64 个操作。构造使用新的稳定场景内 ID，调用只能引用已经构造的实例及声明的方法。方法参数和返回值属于有界 JSON 数据，不支持任意 Python 对象、模块上传、动态导入插件、异步协议或宿主文件。场景内保持实例状态，场景之间使用新的 WASI 实例。构造输入保证合法；构造失败是运行错误。声明的方法异常按类型验证，异常文本不作为成绩或反馈。

页面、公开样例和本地练习包展示同一接口和操作序列。Run 只运行公开场景，不计入完成；正式结果仍由服务端产生，进入已有提交历史、版本证据、学习进度、项目/活动和自愿公开成果。中英界面给出接口专用提示；内容翻译继续使用已有明确回退。

## 执行与信任边界

保留现有 WASI 解释器和资源政策。可信主机只校验有界声明数据，不在宿主编译或执行学员代码。固定 Python 驱动在 WASI 内编译学员源码、创建实例并依序调用方法，生成返回值/异常类型记录。控制器独立比较受保护预期值；预期值不传入 guest。驱动输出不包含可信 verdict、分数或权限。

驱动不是安全隔离机制。学员可能修改 guest 内的模块或输出，因此控制器仍将整个返回记录视为不可信，只接受完整结构并逐值核对；stdout、异常文本和隐藏场景内容不会回传。错误分类保留语法、运行、时间、内存、输出和平台故障的区别。平台取消或租约丢失必须传播，不能变成 Wrong Answer。

显式增加 WASI 的 API 调用方法，gVisor 适配器拒绝该契约。新增驱动、验证器和启动探针纳入策略摘要，旧 receipt 无法授权新版本。每场景一次有界沙箱调用，沿用现有每日预约/消费规则；操作数不能扩大单次 128 MiB、fuel、15 秒及输出限额。每次调用前继续检查租约。

## 方案取舍

- 仅把操作列表交给普通 `solve` 函数：无法验证类接口及多个实例，因此不采用。
- 宿主导入学员包或执行测试：破坏现有隔离边界，因此不采用。
- 多文件包、任意框架和原生扩展：需要独立文件/依赖契约，超出本次有状态 JSON API 切片；本次不宣称覆盖这些形式。
- 使用现有 WASI 承载固定驱动：复用已经验证的隔离、队列与结果体系，新增契约仍须真实正确/错误程序验证。

## 内容、兼容性与验证

新增内容版本，不改写旧题目、项目和活动的固定摘要。没有新数据库表或 HTTP 发布接口。内容 schema、严格导入、公开投影、本地 CLI、资源预约、可信证据、筛选、模板和提示预览同步支持该契约；未知或混合契约字段必须拒绝。

验证包括：声明/操作/预期结构及预算，隐藏预期不进入 guest，实例隔离，准确的返回与异常语义，参考解与针对性错解，语法/资源/输出/隔离失败，取消传播，Run 与正式完成区别，跨账号访问、导出与删除、本地工具和自愿分享。最终运行真实 PostgreSQL/WASI、浏览器及新冻结镜像；不以模拟回包替代执行证据。GPU、可选 gVisor、外部 CI/部署和授权决定继续按需求追踪保留。
