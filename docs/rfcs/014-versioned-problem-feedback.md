# RFC-014：绑定版本的题目反馈

状态：接受，PostgreSQL、固定镜像及 E→F HTTPS 升级验证通过，2026-10-24。对应 PRD §7.2 的题目内容反馈、错误报告和修订建议。证据见 [F 验收](../acceptance-f.md)。

题目页目前可以进入讨论和题解，但没有明确的题目反馈入口或可筛选的反馈类型。本次在现有 `community.Post` 中增加 `feedback`，必须绑定一个已发布题目的具体版本；旧版本仍可选择，题目更新不会改写反馈的版本。反馈正文说明出错位置、复现步骤、预期与实际表现，或建议的修订及理由。

沿用现有草稿、主动送审、审核、评论、修改、撤回、删除、限流和账户导出流程。保存草稿不公开，主动送审才向审核者显示，通过后正文及用户名公开。题目下线后停止公开关联反馈。界面区分公开反馈与社区违规内容的私有举报。审核通过仅表示反馈可以公开；是否修订题目及修订后的版本，由维护者按内容贡献流程处理，可在评论中说明。反馈不会自动改变题目、判题结果或个人进度。

题目页提供带版本预选的反馈入口，社区支持反馈类型筛选，审核队列支持只看待审题目反馈。中英文界面与既有权限边界一致。表单和数据库均要求反馈具有版本；新增迁移只增加类型选项和约束，不增加表、角色权限、网络服务或执行契约。

不另建独立工单体系，因为目前要求可由已有审核和讨论流程完成。验证应覆盖历史版本保留、草稿隔离、公开与撤回、下线、筛选、表单和数据库约束、导出与删除；实际 PostgreSQL 迁移、HTTPS 浏览器和新冻结制品分别留下证据。旧迁移、原内容目录和原暂存区保持原样。
