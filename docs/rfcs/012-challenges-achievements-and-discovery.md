# RFC-012：挑战活动、私有成就与完整题型发现

状态：已实现并通过本地联合验收，见 [D 验收](../acceptance-d.md)，2026-10-24。逐项复核 PRD §3.3、§7.2 后发现：现有题型选择器遗漏三类专业契约；已有普通榜单，但尚无独立挑战活动和成就入口。本文补充这些可本地验证的功能，不改写 GPU、公开运营及许可仍待后续确认的边界。

## 题库发现

筛选项从当前发布题目的实际契约产生，覆盖 Python、JavaScript、完整程序、ML、科学计算和受控工具 Agent。标签、语言、运行条件及正式提交的预约单位均来自可信契约/发布内容，不接受用户自报资源。允许选择适合当前环境的题目、语言或库要求，以及预约单位上限；不显示不存在的 GPU、外部库支持。未知筛选值返回明确空结果，分页保留条件。不能把当前评测暂不可用混同为题目不存在。

## 挑战活动

活动是由可信维护者发布的独立对象，包含名称、说明、UTC 起止时间、明确规则和固定版本任务。所有参与都是自愿的；加入记录和完成进度默认私有，公开页面不展示参与者名单。加入不会自动公开已有成绩，也不会限制用户在活动外正常练习。

采用独立 `challenges` 应用：稳定活动身份、不可变修订、按顺序显示的题目版本绑定和本人加入记录。每个修订最多 30 个不同任务，内容导入有大小/类型/引用/摘要限制。可信管理命令发布或撤回；Web 对活动、修订和任务表只读，仅可写本人的加入记录；worker 不读活动表。修订不覆盖既有参与记录，版本更新后旧参与者仍按原修订查看自己的结果。

活动按实际 UTC 起止时间显示未开始、进行中、已结束。用户可以提前加入；只有任务的可信正式 Accepted、提交时间和完成时间均落在活动窗口内，且提交不早于本人本次加入时间，才计入该任务。Run、平台故障、伪造/不完整结果、他人结果、其他题目版本或窗口外结果均不计入。退出删除加入记录；重新加入按新的时间开始统计，不恢复此前参与记录。活动结束后仍可阅读和正常练习，后续提交不改变该次活动进度。

不新增跨题型总分或速度总榜。单题自愿公开成果继续使用既有相同版本/评测环境分组；活动内展示自己的完成任务数和逐题证据，不将不同专业指标混合排名。任务下线时停止显示正文与指标；历史版本只读，不绕过现有提交准入。账号导出包括本人的参与修订及时间；删除账号级联清除加入记录，不删除公开活动定义。

选择独立版本模型，而不把普通学习路径或项目改名为挑战：活动具有独立时间窗口和参与同意。避免默认公开参与列表、客户端报完成、积分商城或自动发证，这些不能提供客观学习证据。

## 私有成就

成就是可核验的练习事实，不代表知识掌握程度或资质。初始规则包括首次正式通过、不同题目的正式通过、不同评测方式的正式通过及完成固定版本项目/挑战。显示每项规则、实际证据数量和当前状态，不按重复提交刷量。全部从本人可信正式记录及固定任务证据计算，页面说明下线/失效证据可能改变当前展示；不建立永久证书或自动公开奖章。

成就入口归属私有学习空间；不从 URL 接受另一个用户身份。导出包含当前推导结果及规则标识，源码仍只存在本人既有导出。删除账号不会在公开空间留下成就。默认不参与活动、榜单或社交的用户仍可完整练习。

## 验证与迁移

先验证筛选组合、未知值、分页及中英文本，再验证活动导入的不可变版本/完整回滚、加入/退出、起止边界、可信证据筛选、跨账号隔离、下线和导出删除。新增表同步进入数据库角色、Docker 和发布源码范围；真实 PostgreSQL 检查只读内容表、私有参与表及 worker 拒绝。

实际 Chromium 流程需要两账号和真实 WASI：自愿加入、自由选择任务、正式通过更新本人进度、他人不能读取、退出及删除生效；也覆盖英文和键盘导航。新 schema 的固定镜像及从 C 版本升级另行验收。原 C 回执保留原范围，不用新增单元测试替代真实部署。
