# B2 多语言练习、项目与公开成果验收

日期：2026-10-23。范围见 [ADR-010](adr/010-practice-projects-sharing.md)。当前交付方向为可本地验证的自部署版本；维护者已明确公开运营和许可证选择留待后续。专业 CPU 评测、组织题库和智能学习仍在下一批实施，不将本批视为全部 PRD 完成。

## 交付内容

同一知识、题库、账户和队列支持 Python 函数、JavaScript 函数及 Python 完整程序。目录包含 22 题、43 个知识节点和四条路径；原 B1 的 18 题、38 节点保持不变。全部参考实现覆盖 157 个真实 WASI 用例，45 个针对性错解和 22 个恒空变体被拒绝。完整程序最终任务用于四阶段传感器数据分析项目，阶段固定不可变题目版本，可以自由跳转。

中英界面、精确源版本翻译和明确的缺译回退已经实现。当前 20 个知识节点、8 题有英文内容；项目界面可切换英文，未翻译的计划正文明确保留原文。翻译不能改变代码、测试、关系或评分规则。

CLI 下载公开包，在经过摘要校验的本地 WASI 中运行公开样例，以令牌提交明确版本源码，并查询服务端真实结果。相同幂等标识的重试不创建第二份任务；本地结果不计正式成绩。令牌一次显示、只存摘要、有用途和有效期限制，支持撤销和账户恢复时统一失效。

主页默认关闭，每个成果需单独明确分享，关闭主页会撤回全部成果。公开投影不含源码、隐藏测试或主机信息；榜单仅在同题版本、同评测指纹内按通过用例量比较，同分同名次，不以耗时或跨学科总分排序。

## 实测证据

- PostgreSQL＋真实 WASI 全回归：**721 passed、1 SQLite 专属 skipped**，`test-results/b2-postgres-wasi-full.xml`，979.84 秒。临时数据库容器和卷已清理。
- 冻结镜像首次安装：`test-results/release-b2-acceptance.json`，通过。103 个联合启动探针、非 root/只读容器、worker 内部网络、无宿主挂载或 Docker socket、Run/WA/AC、三种契约的 CLI 提交与分享、英文和项目浏览器、排空/恢复及错误制品拒绝均验证。
- 回环 HTTPS 功能浏览器：`test-results/b2-production-browsers/`，通过。真实表单完成令牌签发、6 个正式正确/错误任务、幂等重试、私有项目进度、显式分享与撤回、导出和令牌撤销；合成账号实际删除。
- B1→B2 schema 升级：`test-results/deployment-b2-upgrade/deployment-acceptance.json`，通过。保留原 18 题目录、旧用户源码与 AC、笔记、收藏、阅读声明及社区草稿；实际备份/恢复、五个新增迁移、十张新表权限及序列得到验证。Web 只能写四张私有数据表，六张内容表只读，worker 无任何新表权限。
- 升级后真实 HTTPS 验证令牌幂等提交、旧/新环境结果的明确分享、主页关闭、导出、撤销和完整社区审核流程。知识快照回填只记录现存内容，不自动发布译文或新项目。
- 首次安装与升级的私有容器、网络、卷和进程均清理；升级回执 `remaining_owned_resources={}`。

生产 HTTPS 独立复测通过，回执为 `test-results/b2-production-final/production-acceptance.json`。单 worker 处理六账号并发正式提交，每个任务六个实际用例，全部 Accepted，最慢总完成时间 36.3239 秒。八客户端各轮共 120 次浏览，空闲 p95 为 0.1586 秒，判题期间 p95 为 0.1886 秒，均无错误；worker 停机后的拒绝接单、继续阅读/保存草稿以及伪造 IP 不能绕过限流通过。这里是当前主机本地回归指标，不是面向任意负载的容量承诺。

先前失败保留：前两次整套尝试分别受到验收脚本旧 120 秒总超时和同 IP 累计账户操作限流影响；第三次六账号突发超过既定 60 秒目标，当时多个独立验收 worker 争用同一 CPU。限流、单个用户程序限制和性能目标均未放宽。最终复测在其他自建评测 worker 停止后运行；可选 AI 原型若运行则固定 CPU 1/2，本次 WASI 使用 CPU 0。
